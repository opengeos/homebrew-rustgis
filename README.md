# RustGIS Homebrew tap

A [Homebrew](https://brew.sh) tap for [RustGIS](https://rustgis.app), a fast, free and
open-source GIS in pure Rust.

## Install

The desktop app (macOS, Apple Silicon and Intel; signed and notarized):

```sh
brew tap opengeos/rustgis
brew trust opengeos/rustgis      # Homebrew 5.1 and later
brew install --cask rustgis
```

The command line tool and MCP server, `rustgis-cli` (macOS and Linux):

```sh
brew install opengeos/rustgis/rustgis-cli
```

`brew trust` approves a tap other than Homebrew's own once; skip it on older Homebrew.

## Upgrade and uninstall

```sh
brew upgrade --cask rustgis
brew upgrade rustgis-cli
brew uninstall --cask --zap rustgis     # --zap also removes settings, plugins and caches
brew uninstall rustgis-cli
```

## How it is updated

`Casks/rustgis.rb` and `Formula/rustgis-cli.rb` are generated by
[`packaging/homebrew/render.sh`](https://github.com/opengeos/RustGIS/tree/main/packaging/homebrew)
and pushed here by the RustGIS *Package managers* workflow after every release. Do not edit them
by hand.
